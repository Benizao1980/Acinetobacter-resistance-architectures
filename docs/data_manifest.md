# Data manifest

Do not commit raw clinical reads or large genome collections to GitHub.

| Dataset | Public destination | GitHub content |
|---|---|---|
| Regional raw reads | NCBI SRA | accession/manifest only |
| Regional BioSamples | NCBI BioSample | accession/metadata manifest |
| Regional/global assemblies | NCBI/pubMLST/Figshare as appropriate | links/manifests only |
| Full GWAS evidence | Figshare | prioritised summary/source scripts |
| ML sample-level predictions | Figshare | scripts + compact source tables |
| BactDating/SkyGrowth outputs | Figshare | scripts/config + summary |
| Figure numerical source data | Figshare | optional compact copies |
